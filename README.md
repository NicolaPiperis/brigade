# brigade

Nicola Piperis's Claude Code plugins, run like a professional kitchen brigade.

Inspired by [Matt Pocock's skills](https://github.com/mattpocock/skills).

| Plugin | What it does |
|---|---|
| `mise-en-place` | A guided, human-in-the-loop development workflow backed by a personal knowledge base, the pantry. |

## Install

```
/plugin marketplace add NicolaPiperis/brigade
/plugin install mise-en-place@brigade
```
